# Definition of Ready dan Done — usulan

## Ready
Tujuan, requirement, scope dan PIC jelas; acceptance criteria dapat diuji; dependency dan estimasi tersedia; pekerjaan dapat selesai dalam sprint.

## Done
Scope dan acceptance criteria terpenuhi, hasil diperiksa, pengujian relevan dan hasil dicatat, tidak ada critical defect yang belum ditangani, PR direview dan terintegrasi bila relevan, dokumentasi diperbarui, bukti tersedia dan status Project diperbarui. PR saja belum Done.

## Bukti tambahan dan alur

Catat hasil uji aktual, bukti PR dan review, defect kritis, integrasi serta pembaruan Project. Peer review dan merge bila relevan diperlukan sebelum Done. Checklist ini adalah usulan sampai disepakati; tidak menjadi bukti bahwa suatu issue selesai.
