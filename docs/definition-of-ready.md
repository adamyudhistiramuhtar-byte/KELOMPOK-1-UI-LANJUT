# Definition of Ready — usulan tim

Sebelum issue dipilih untuk sprint:
- [ ] Requirement dan sumber jelas; asumsi belum disetujui ditandai.
- [ ] Scope dan acceptance criteria dapat diuji.
- [ ] PIC dan estimasi relatif size tersedia.
- [ ] Dependency dan risiko diketahui; pekerjaan dapat selesai dalam sprint.
- [ ] Untuk UI: fondasi desain, token, komponen dan gate terkait tersedia serta disetujui.

Status ini tidak otomatis mengubah komitmen sprint. Konfirmasi dilakukan saat planning/refinement.
