# Project Brief — DRAFT / PERLU KONFIRMASI

## Latar belakang dan problem statement
Tugas kelompok meminta satu website portofolio untuk memperkenalkan anggota dan karya mereka. Kebutuhan untuk menyatukan informasi ini berasal dari instruksi proyek; belum ada bukti wawancara, survei, observasi, atau klaim masalah aktual yang dapat diverifikasi.

## Visi dan product goal
Menyediakan ruang responsif agar pengunjung mengenali enam anggota, kompetensi, karya, proyek dan kontak profesional yang disetujui. Website bernama Kelompok 1; target pengguna adalah pengunjung publik yang ingin mengenal anggota dan karya mereka. Stakeholder: enam anggota dan dosen mata kuliah; kebutuhan stakeholder lain belum dikonfirmasi.

## Scope
Dalam scope: beranda, Tim, profil individu, showcase dan detail proyek, direktori kontak; sedikitnya satu API relevan dengan komunikasi nyata, state dan retry; pengujian, dokumentasi, deployment dan presentasi. Di luar scope: login, registrasi, CMS, admin dashboard, pembayaran, form kontak tim, email kolektif dan data tanpa izin.

## Kebutuhan dan batasan
Kebutuhan produk dan kualitas terdapat di [requirements](requirements.md); routing, komponen reusable, props/composition, state, responsif, aksesibilitas dan API nyata merupakan kebutuhan teknis. Stack dan penyedia API belum disepakati; Vue merupakan prioritas usulan, bukan keputusan. Gunakan foto dan karya yang mendapat izin; aset final bukan gambar AI. Anggaran, batas browser dan jadwal presentasi aktual belum tersedia.

## Kriteria keberhasilan dan deliverables
Pengunjung dapat menjalankan alur enam halaman, mencari/filter sedikitnya tiga proyek dan menggunakan direktori kontak; hasil uji dan bukti API disediakan. Deliverables: website yang dapat diakses, repository, GitHub Project, SRS, user flow, arsitektur, kontrak API, test cases dan hasil aktual, deck, ringkasan kontribusi, dokumentasi Scrum serta weekly updates. Penerimaan akhir memerlukan hasil uji dan persetujuan tim/dosen sesuai ketentuan; belum diklaim tercapai.

## Tim dan milestone akademik
Adam adalah Project Manager dan System Analyst; seluruh enam anggota berkontribusi pada produk. Pembagian awal: [team responsibilities](team-responsibilities.md). Sprint 1: 23 November–6 Desember, core member flow; Sprint 2: 7–20 Desember, feature integration; Sprint 3: 21–27 Desember, final delivery. Jadwal baseline mengikuti Asia/Jakarta dan dapat disesuaikan dengan ketentuan dosen.
