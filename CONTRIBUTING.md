# Contributing — usulan untuk disepakati

Gunakan GitHub Flow: issue → branch (`feature/issue-number-short-description`, `fix/…`, `docs/…`, `test/…`) → commit → pull request → minimal satu peer review → merge → Done. Usulan Conventional Commits: `feat:`, `fix:`, `docs:`, `style:`, `refactor:`, `test:`, `chore:`. PR memuat deskripsi, issue terkait, screenshot untuk UI, dan hasil uji relevan. Jangan memublikasikan data personal atau karya tanpa persetujuan. Jangan mengubah branch protection tanpa kesepakatan yang diperlukan.

## Engineering governance — proposed for review

Read [engineering standards](docs/engineering/engineering-standards.md), [Git workflow](docs/engineering/git-workflow.md), [review policy](docs/engineering/code-review-policy.md), [repository hygiene](docs/engineering/repository-hygiene.md) and [onboarding](docs/engineering/developer-onboarding.md). Install repository-local hooks with `sh scripts/install-hooks`; the team must review and adopt this governance through PR #39's related pull request before it is enforced on main. Existing branches and PRs are not renamed or rewritten automatically.
